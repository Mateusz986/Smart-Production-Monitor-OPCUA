# Smart-Production-Monitor-OPCUA
Real-time industrial production monitoring system powered by CODESYS Control Win V3 and OPC UA. Śledzi na żywo liczbę elementów, wydajność linii, awarie oraz realizację norm godzinowych przy użyciu klienta UaExpert, wykorzystując bezpieczną autoryzację opartą na certyfikatach oraz szyfrowaną komunikację.
